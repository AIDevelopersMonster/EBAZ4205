# EBAZ4205 — публичные доказательства испытаний

[Матрица результатов](../../docs/VERIFICATION_MATRIX_RU.md) · [Главная](../../README.md)

Каталог предназначен для **обезличенных** логов UART, снимков терминала, метаданных испытаний и контрольных сумм собственных тестовых файлов. Наличие ссылки или записи в матрице не означает, что полный исходный raw-лог уже опубликован здесь.

**Запрещено публиковать:** приватные SSH-ключи, `authorized_keys` владельца, заводские бинарные образы без прав, полные NAND-дампы, пароли, токены, MAC/серийные номера, позволяющие идентифицировать владельца, персональные данные.

Каждый будущий отчёт должен указывать плату/ревизию, Linux/bitstream, дату, команду, фактический вывод и пределы вывода.
