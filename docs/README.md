# Документация EBAZ4205 — оглавление

**EBAZ4205 Reference & Developer Guide.** Этот раздел предназначен для владельцев платы, разработчиков Linux/ARM/FPGA, ремонтников и авторов учебных лабораторий.

> **Как читать:** начинайте с актуальных обзорных руководств и [матрицы подтверждения](VERIFICATION_MATRIX_RU.md). Файлы с номерами **EBAZ-03…23** — подробные оригинальные технические журналы и воспроизводимые опыты. Ранние записи отражают состояние **на дату измерения** и могут содержать впоследствии исправленные предположения. Историю не переписываем задним числом.

## Обозначения достоверности

**PASS** — подтверждено выводом нашей платы (обычно одного экземпляра, одной ревизии и конфигурации). **REFERENCE** — сведения схемы/репозитория третьих лиц, не наша аппаратная проверка. **PENDING** — приготовлено, но не проверено. **UNKNOWN** — не доказано. **RISK** — действия, которые могут нарушить работающую систему.

Для любой новой информации указывать конкретную версию Linux/FPGA, дату, источник, вывод теста и пределы применимости. Не публиковать ключи, дампы NAND, закрытые прошивки и чужой код без права распространения.
