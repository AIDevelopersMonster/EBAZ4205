# EBAZ4205 — архитектура ARM/FPGA и аппаратные интерфейсы

**Справочник, 07.11.2026.** Объект: EBAZ4205 с **Xilinx Zynq-7000 XC7Z010**. Разделяйте аппаратные возможности кристалла, разводку конкретной платы, активную конфигурацию FPGA и драйверы Linux — это четыре разные вещи.

[Матрица фактов](VERIFICATION_MATRIX_RU.md) · [Подробная карта EBAZ-21](EBAZ-21_BOARD_PINOUT_AND_FACTORY_FPGA_RU.md) · [GPIO EBAZ-23](EBAZ-23_PS_MIO_EMIO_AVAILABLE_PINS_RU.md)

## 1. Что внутри XC7Z010

\`\`\`text
              XC7Z010 (Zynq-7000 SoC)
┌──────────────────────────────────────────────────────────┐
│ PS — аппаратная процессорная система                     │
│   2 × ARM Cortex-A9 · DDR controller · NAND · SDIO        │
│   UART · GPIO · GEM Ethernet · SPI · I2C · таймеры        │
│   MIO: 54 контакта непосредственно PS                      │
│   EMIO: до 64 GPIO, выход через PL по конфигурации         │
├──────────────────── AXI / EMIO ───────────────────────────┤
│ PL — программируемая логика FPGA                          │
│   HDL/IP, маршрутизация сигналов, AXI периферия            │
│   контакты DATA, LED6, FAN и Ethernet PHY через PL         │
└──────────────────────────────────────────────────────────┘
             │
             ├─ внешняя микросхема DDR3, не внутри Zynq
             ├─ внешняя NAND Flash с U-Boot / Linux / PL
             ├─ разъём microSD → PS SDIO
             └─ RJ45 → Ethernet PHY → PL/EMIO → PS GEM
\`\`\`

**Два ARM-ядра «жёстко зашиты» в кремний PS; FPGA их не создаёт.** FPGA при этом может содержать дополнительные пользовательские вычислительные блоки, включая softcore CPU.

## 2. Загрузка системы и носители

| Узел | Устройство / текущий статус | Примечание |
|---|---|---|
| NAND | 128 МиБ, разделы MTD; текущий корень \`mtd6\` JFFS2 64 МиБ | Исходная майнинговая Linux очищена и сохраняет загрузку из NAND |
| RAM | Внешняя DDR3, номинально 256 МиБ | PS DDR controller |
| FPGA bitstream | Заводской PL хранится отдельно в NAND, загрузка через U-Boot | Не заменять без восстановления Ethernet |
| SD | PS SDIO0, карта SDHC SC16G 14,8 GiB на испытанном экземпляре | \`/dev/mmcblk0p1\`, VFAT, автомонтирование \`/run/media/mmcblk0p1\` |
| SD boot | **Не проверялся на нашей плате** | Переключение boot strap требуется только для первичной загрузки с SD |

## 3. Внутренние интерфейсы и реальные адреса

| Интерфейс | На нашем экземпляре | Статус |
|---|---|---|
| PS GPIO | base=906; MIO20 → Linux GPIO926, MIO32 → GPIO938 | SW2/SW3 INPUT PASS |
| PS UART | \`ttyPS0\`, 115200 8N1 | UART PASS |
| PS SDIO | \`e0100000.sdhci\`, \`mmc0\` | SDHC/VFAT/automount PASS |
| PS Ethernet GEM | \`e000b000\` → PL/EMIO → PHY | Ethernet/DHCP/SSH PASS |
| AXI BRAM (PL) | \`0x40000000\`, Device Tree window 0x2000 | Read-only 128 байт PASS; запись неизвестна |
| UARTLite (PL) | \`0x42c00000\`, \`/dev/ttyUL2\` | Драйвер/обмен подтверждены |
| AXI GPIO \`0x41200000\` | **НЕ подтверждён у нас** | Это адрес из чужого экспериментального bitstream, не используйте его вслепую |

## 4. Выводы и разъёмы

| Группа | Соединение | Не путать с |
|---|---|---|
| MIO20/MIO32 | Кнопки SW2/SW3, физически испытаны | PL-выводами |
| MIO40…45, MIO34 | SDIO + card detect по схемам | Загрузочными резисторами R2577/R2584 |
| LED6 green/red | Контакты **W13/W14** PL Bank 34 | Гарантированным управлением через GPIO960/961 в заводском bitstream |
| FAN J3 | PL **U12 PWM**, **V13 SPEED** | PS MIO GPIO |
| FAN J5 | PL **V12 PWM**, **V15 SPEED** | PS MIO GPIO |
| DATA1/2/3 | По справочным XDC **42 сигнальных PL-линии** | Гарантированно свободными линиями текущего bitstream |
| Ethernet PHY | PL-проводники MII/MDIO | Чисто PS MIO Ethernet |
| RTC I2C | MIO26/27 по опубликованной схеме | Подтверждённым аппаратным RTC — на нашем Linux его probe ранее не удался |

Полная таблица: [hardware/README.md](../hardware/README.md).

## 5. Заводская роль FPGA в майнере

Плата использовалась как управляющая Ebang Ebit E9+; массовый SHA-256 выполнялся **внешними ASIC**, а не двумя ARM или FPGA самой платы. Инженерно вероятны: управление интерфейсами трёх ASIC-плат, синхронизация, приём телеметрии и результатов, PWM/тахометры и PHY Ethernet. **Точный заводской RTL и протокол работы с ASIC не восстановлены**: этот перечень — архитектурная гипотеза, а не декодированный netlist.
