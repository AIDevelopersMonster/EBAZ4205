# EBAZ4205 — матрица подтверждённых возможностей

**Срез по состоянию на 07.11.2026.** Результаты относятся к **нашему одному опытному экземпляру EBAZ4205** после очистки майнингового ПО, с NAND Linux 4.6.0-xilinx и сохранённым заводским FPGA bitstream. Не являются гарантией для всех аппаратных ревизий, новых устройств или сторонних прошивок.

**Обозначения:** \`PASS\` — подтверждено реальным исполнением/выводом; \`REFERENCE\` — известно по схемам и чужим проектам; \`PENDING\` — готово к испытанию, но не пройдено; \`UNKNOWN\` — данных недостаточно. Для PASS приводится конкретное доказательство или журнал.

## Что известно по схеме, но ещё не проверено как функция

| Узел | Статус | Предел достоверности |
|---|---|---|
| Красный/зелёный LED6 W14/W13 | **REFERENCE** | Физическая разводка подтверждается XDC/схемой; программный контроль в нашем factory bitstream неизвестен |
| FAN J3/J5 PWM и SPEED | **REFERENCE** | PL U12/V13, V12/V15; не выполнен тест с вентиляторами; оптообвязка зависит от ревизии |
| 42 сигнальных линии DATA1–3 | **REFERENCE** | Справочная карта 14 на разъём; свободность GPIO в текущей FPGA не доказана |
| Управление FPGA через новые AXI регистры | **PENDING** | Собственный безопасный write/readback IP в текущем PL не развёрнут |
| Hot insertion/removal microSD | **UNKNOWN** | Пока подтверждена SD-карта, установленная при загрузке |
| Загрузка SoC с microSD вместо NAND | **UNKNOWN** | Загрузочные резисторы не переключались; теста SD boot нет |
| Собственные FPGA bitstream и аппаратные PWM | **PENDING** | В текущем публичном репозитории нет испытанного собственного проекта для PL |
| Полная схема заводского майнера / протокол ASIC | **UNKNOWN** | Оригинальная логика PL и карта регистров майнера не восстановлены |

## Как воспроизводить и документировать PASS

Каждый новый лабораторный результат должен фиксировать **что проверяли; на какой плате/ревизии; ОС/DT/bitstream; команды; реальный вывод; дату; пределы вывода**. Для реестра не подходят формулировки «должно работать», «есть в XDC» или «работает у другого автора».

Старые документы часто содержат этапы вида «ожидается», «ещё не проверено». Это **исторические этапы**, а не текущий итог; эта матрица — актуальная точка входа. За детальными журналами идите в [полный каталог](README.md).

**Безопасность:** публикация материалов не предполагает размещение factory bitstream, полных дампов NAND, host keys, персональных конфигураций SSH и чужого исходного кода без прав на распространение.
