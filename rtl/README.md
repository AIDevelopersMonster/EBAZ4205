# EBAZ4205 — FPGA/RTL

[Главная](../README.md) · [Архитектура](../docs/ARCHITECTURE_RU.md) · [Аппаратная карта](../docs/EBAZ-21_BOARD_PINOUT_AND_FACTORY_FPGA_RU.md) · [Сторонние проекты](../docs/EBAZ-21_COMMUNITY_PROJECTS_REVIEW_RU.md)

Это каталог для **нашего собственного исходного HDL, constraints, тестбенчей и скриптов сборки**. В настоящий момент готового собственного FPGA-дизайна, подтверждённого на нашем экземпляре и опубликованного в данном каталоге, **нет**.

Текущая заводская конфигурация PL сохраняет Ethernet через EMIO/MII и содержит наблюдаемые интерфейсы AXI BRAM и UARTLite. **Нельзя** считать, что новый bitstream с простым LED-миганием автоматически сохранит Linux Ethernet. Не загружайте чужие `.bit` или `.bin` поверх рабочего PL без UART/JTAG восстановления и проверки PHY clock.

Примеры других авторов находятся в [атласе сторонних проектов](../docs/EBAZ-21_COMMUNITY_PROJECTS_REVIEW_RU.md). Сами исходники авторов сюда не копируем без подтверждения лицензии и условий распространения.
