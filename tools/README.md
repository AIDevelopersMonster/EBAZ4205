# EBAZ4205 — инженерные инструменты

[Главная](../README.md) · [Документация](../docs/README.md)

- [ebaz_jffs2_find_inode.py](ebaz_jffs2_find_inode.py) — **только чтение** резервного образа NAND JFFS2; поиск и анализ inode/dirent/CRC на ПК.

Это офлайн-утилита для разработчика, **не программа для запуска на Zynq**. Не передавайте в неё дамп с конфиденциальными данными для публичной публикации. Источники методики: [EBAZ-16](../docs/EBAZ-16_JFFS2_CRC_AUDIT_RU.md) и [EBAZ-19](../docs/EBAZ-19_CLEAN_JFFS2_REBUILD_RU.md).

Полные сырые дампы NAND, bitstream и ключи не следует загружать в открытый репозиторий.
