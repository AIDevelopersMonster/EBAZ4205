# EBAZ4205 — воспроизводимые релизы

[Главная](../README.md) · [Комплектная SD](../sdcard/README.md) · [Матрица испытаний](../docs/VERIFICATION_MATRIX_RU.md)

Каталог предназначен для **проверенных релизных пакетов**: номер версии, список файлов, хеши, инструкция установки, тест приёмки и обратимый откат.

Сейчас публичный репозиторий содержит исходники и экспериментальные журналы; **серийный NAND-образ, универсальный bitstream или готовый мастер-образ SD для всех ревизий не опубликованы**. Не рассматривайте содержимое `software/` или `sdcard/` как промышленную прошивку, готовую к массовой установке.

Для подготовки перед продажей см. [EBAZ-15](../docs/EBAZ-15_CLIENT_HANDOFF_RU.md) и [EBAZ-22](../docs/EBAZ-22_COMMERCIAL_PRODUCT_BRIEF_RU.md).
