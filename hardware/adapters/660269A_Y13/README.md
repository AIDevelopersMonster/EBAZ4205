## Наша конкретная плата (по пользовательским фото)

| Наблюдаемая маркировка/узел | Что видно | Уровень достоверности |
|---|---|---|
| 660269A_Y13 | надпись на зелёной PCB | визуально подтверждено |
| KEY1…KEY4 | четыре тактовые кнопки | наличие подтверждено; package pin / active level неизвестны |
| LED1…LED4 | четыре площадки/светодиодных узла с резисторами | наличие подтверждено; package pin неизвестны |
| DATA1 / DATA2 / DATA3 | три ответных разъёма основной EBAZ4205 | визуально; электрические цепи не прозвонены |
| HDMI | металлический видеопорт | наличие подтверждено; вывод сигнала не проверен |
| 5V IN | надпись возле разъёма DC | маркировка подтверждена, фактическая разводка питания и токи не измерены |
| 3.3V, GND и дополнительные гребёнки | подписи и контакты на плате | маркировка подтверждена, безопасное подключение требует схемы и измерений |

**Это не схема платы и не результат лабораторной проверки GPIO.** Положения пинов и текст шелкографии — подсказки для прозвонки, но не основание загружать XDC или подавать питание. Параллельное питание через несколько входов может повредить оборудование; схему входа следует установить до подачи новых источников.

## Что требуется для hardware pinmap

1. Фото обеих сторон PCB, ориентация разъёмов, обозначение первого контакта и посадки на EBAZ4205.
2. Прозвонка KEY1–KEY4, LED1–LED4 и HDMI при **выключенном питании**, с привязкой к DATA1–3 и конкретным Zynq package pin.
3. Проверка питания, обвязки стабилизатора, уровней логики, соответствующих банков PL.
4. Сопоставление с [нашими существующими CSV](../../README.md) и **раздельная** фиксация подтверждённых измерений и внешних XDC.
5. После верификации создать отдельную таблицу 660269A_Y13_PINMAP.csv со столбцами: connector, contact, net, zynq_package_pin, bank, direction, active_level, evidence, status.
