# EBAZ4205 Developer SD — содержимое комплектной microSD

[Главная](../README.md) · [Быстрый старт](../docs/QUICKSTART_RU.md) · [Аппаратная верификация](../docs/VERIFICATION_MATRIX_RU.md)

**Концепция:** существующая NAND Linux продолжает загружаться как прежде, а microSD содержит дополнительные лабораторные программы, справочники и файлы для работы. Новый пользователь `sd` **не нужен**: в нашей исследовательской системе используется `root`.

## Проверенная структура

```text
microSD (VFAT; автоматическое монтирование Linux)
└── EBAZ4205/
    └── tests/
        └── buttons/
            ├── test-buttons.sh
            └── README.md
```

Реальная SDHC 16 ГБ (`SC16G`, 14,8 GiB) определилась как `/dev/mmcblk0p1` (`UUID=751F-7A24`, VFAT) и автоматически смонтировалась в **`/run/media/mmcblk0p1`**. Это путь **на нашей подготовленной плате**; на другой ОС или после изменения разделов он может отличаться.

## Проверенный тест кнопок

```sh
sh /run/media/mmcblk0p1/EBAZ4205/tests/buttons/test-buttons.sh
```

Физический результат: `SW3, SW2, SW3, SW2`, обе кнопки идентифицированы. [Описание теста и режимов BusyBox](EBAZ4205/tests/buttons/README.md).

**FAT32 не обеспечивает нормальные UNIX-права и символические ссылки**: запускаем shell-файл через `sh`. Для полноценного Linux workspace ext4 на второй раздел **только планируется**; в текущем публичном репозитории нет готового проверенного образа SD для тиража. Не переформатируйте уже работающую карту с данными.

## Разработка будущего комплекта

Планируемые, **пока отсутствующие** разделы могут включать: `examples/`, `tools/`, `fpga/`, `docs/`, контрольные суммы и инсталляционные сценарии. Не объявляем их существующими и работоспособными до фактического добавления и аппаратной проверки.

Важное разделение: **microSD как накопитель под NAND Linux — PASS**, а **загрузка с SD вместо NAND — не испытана**.
