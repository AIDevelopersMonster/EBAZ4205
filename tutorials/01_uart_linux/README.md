# LAB-01 — UART и безопасная инвентаризация Linux

**Статус: PASS (на одном подготовленном экземпляре EBAZ4205).**

## Цель
Подключиться к PS UART, увидеть загрузку NAND Linux и прочитать основные сведения о системе **без изменения NAND или FPGA**.

## Аппаратура
EBAZ4205 XC7Z010, совместимый USB–UART адаптер **3,3 В TTL**, общая земля, терминал **115200 8N1**. Не путать UART TTL с RS-232 и не подавать питание через UART без схемы. Наш образ: Linux 4.6.0-xilinx / PetaLinux 2016.4, factory PL.

## Выполнение (на уже загруженной Linux)
~~~sh
uname -a
cat /proc/cpuinfo
df -h /
cat /proc/partitions
cat /proc/mounts | grep -E 'mmcblk|jffs2'
~~~
Ожидаем **реальный вывод своего экземпляра**, не фиксированные цифры чужой платы. Для нашего образца ранее подтверждены 2 Cortex-A9, NAND JFFS2, UART и Linux. Оригинальные логи и действия U-Boot подробно описаны ниже; опасные команды из исторических журналов **не являются** частью этой лабораторной.
