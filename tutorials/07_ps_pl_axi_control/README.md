# LAB-07 — PS → PL AXI4-Lite: управление периферией и HDMI

**Статус: PENDING — собственного AXI4-Lite IP с write/readback на железе пока нет.**

## Предпосылки
- LAB-04 подтвердил **чтение** AXI BRAM в существующем factory PL. Это не доказательство работы нашего будущего регистрового периферийного блока.
- LAB-05 и LAB-06 должны подтвердить реальные выводы и работу соответствующей PL-периферии.
- Нужен тестовый стенд с доступом UART/JTAG и безопасным восстановлением Ethernet/PL.

## План
1. Спроектировать минимальный AXI4-Lite slave с регистрами ID/VERSION, CONTROL, STATUS и readback, задать согласованную карту адресов.
2. Выполнить RTL/AXI тестбенч, проверить read/write, byte strobes и reset.
3. Создать PS7+PL block design и совместимый Linux Device Tree либо контролируемый bare-metal путь.
4. Проверить доступ к регистрам на физической плате и отдельный управляющий эффект (LED/HDMI) при сохранении диагностического UART.
5. Задокументировать фактический лог, адреса, сборку, bitstream SHA и механизм отката.

Полезная внешняя архитектура: [tomorrow56/06_hdmi_test](https://github.com/tomorrow56/EBAZ4205_tutorial/tree/main/tutorials/06_hdmi_test). [Теория и границы нашего эксперимента AXI](../../docs/EBAZ-20_AXI_ARM_FPGA_PRACTICAL_RU.md).

**Безопасность:** не записывать mtd5, NAND или U-Boot env в рамках первого теста; не обещать сетевой доступ после смены PL.
