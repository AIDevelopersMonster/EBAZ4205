# LAB-06 — вывод тестового изображения через HDMI переходника

**Статус: PENDING — тестовый HDMI-сигнал нашей платой ещё не подтверждён.**

## Цель
Вывести собственный тестовый видеошаблон из PL в HDMI 660269A_Y13. Первым этапом — устойчивые цветные полосы или тестовая сетка, **без Linux AXI-управления**.

## Что нужно установить
- Реальная распиновка HDMI/TMDS для ревизии 660269A_Y13, включая полярность дифференциальных пар, банковое напряжение, пригодность подключения.
- Правильные XDC, IOSTANDARD и реализация тактирования/серилизации для выбранного видеорежима.
- Совместимость с нашей схемой загрузки: новое PL может отключить Ethernet, если отсутствует работающий PHY/EMIO тракт.

## Этапы приёмки
1. Прозвонка и документирование выхода.
2. Повторяемая RTL-симуляция генератора таймингов и пикселей.
3. Сборка Vivado без критических DRC/timing нарушений.
4. Аппаратный тест с монитором и фиксация режима (например, 640×480 или 1280×720 — выбрать после проверки).
5. Фото экрана, лог сборки, контрольная сумма артефакта, PASS/FAIL в [матрице](../../docs/VERIFICATION_MATRIX_RU.md).

Внешний пример для исследования, не готовое решение нашей ревизии: [tomorrow56/06_hdmi_test](https://github.com/tomorrow56/EBAZ4205_tutorial/tree/main/tutorials/06_hdmi_test).
