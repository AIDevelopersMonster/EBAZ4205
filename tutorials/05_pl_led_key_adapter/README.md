# LAB-05 — четыре LED и четыре KEY на 660269A_Y13

**Статус: PENDING — ещё нет проверенного на нашем железе RTL, XDC и результата.**

## Цель
Сначала верифицировать электрическую разводку 660269A_Y13 и уровни сигналов, затем создать собственный Vivado-проект для PL: кнопки KEY1–KEY4 управляют LED1–LED4. При необходимости добавить антидребезг.

## Что известно
На наших фотографиях видны KEY1–KEY4, LED1–LED4, маркировка 660269A_Y13, разъёмы к DATA1–3 и GPIO гребёнки. **Физические выводы FPGA и уровни активного сигнала не измерены.** Предположения из чужих XDC нельзя помечать PASS.

## План работ
1. [Зафиксировать ревизию и проверить разъёмы](../../hardware/adapters/660269A_Y13/README.md): непрерывность сигнала, земля, питание, соответствие подписей корпусу Zynq.
2. Составить проверенную таблицу connector → Zynq package pin → LED/KEY, с независимой проверкой напряжения банка и IOSTANDARD.
3. Создать собственные RTL, simulation testbench, XDC и воспроизводимую процедуру сборки в rtl/ или рядом с уроком.
4. **До временной конфигурации PL** подготовить UART/JTAG recovery: factory PL на нашем экземпляре обслуживает Ethernet. Никаких команд записи NAND, mtd5 или U-Boot env.
5. Провести испытание на оборудовании и приложить журнал/видео. Только затем поднять статус до PASS.

Полезные внешние примеры: [tomorrow56](https://github.com/tomorrow56/EBAZ4205_tutorial) и [ZX_BulbuLator](https://github.com/Alex-Electron/ZX_BulbuLator). Ссылки для изучения; исходники автоматически не копируются.

**Не путать:** PASS кнопок SW2/SW3 PS в LAB-02 не является PASS кнопок KEY1–KEY4 PL на переходнике.
