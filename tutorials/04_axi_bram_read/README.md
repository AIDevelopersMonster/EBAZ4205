# LAB-04 — чтение AXI BRAM из ARM Cortex-A9

**Статус: PASS — только read-only 32 × 32-bit (128 байт) на factory PL.**

## Цель
Показать реальное взаимодействие процессорной системы PS с доступным в заводской PL AXI BRAM Controller без записи регистров.

## Исходный проект
[software/ebaz20-bram-reader](../../software/ebaz20-bram-reader/README.md) — исходный код C, Makefile, проверка ARM ELF. Кросс-сборка и отправка на плату описаны в [ARM Toolchain](../../docs/EBAZ-20_ARM_TOOLCHAIN_RU.md).

На **сохранённой и предварительно проверенной** конфигурации нашей платы исполнялся:
~~~sh
/dev/ebaz20-ram/ebaz20-bram-reader --words 32
~~~
Результат: чтение 32 слов с 0x40000000…0x4000007C, маркер EBAZ20_BRAM_READ_PASS, код завершения 0.

## Риски и предел вывода
Даже чтение MMIO при отсутствующем AXI slave может зависнуть. Команда относится **только** к ранее идентифицированному диапазону в factory bitstream; с новым PL может быть небезопасна. Не делать write, не считать содержимое BRAM доказательством восстановленного протокола майнера. Источник: [EBAZ-20 инвентаризация](../../docs/EBAZ-20_SYSTEM_INVENTORY_RU.md).
